# YuvaIntern Week 1 – R Data Analyst Internship

## Project
Data Cleaning and Preliminary Analysis using the public Titanic passenger dataset.

## Files
- `week1_analysis.R` – complete R script.
- `data/titanic.csv` – downloaded automatically when the script runs.
- `outputs/` – cleaned CSV files, summary evidence, correlation matrix and charts generated by the script.
- `Week1_R_Data_Cleaning_Report.docx` – report for the internship submission.

## Run instructions
1. Install R and (optionally) RStudio.
2. Open `week1_analysis.R` in RStudio.
3. Set the working directory to this project folder.
4. Run the script from top to bottom while connected to the internet (the CSV is downloaded from the public source).
5. Review the generated `outputs/` folder and retain your actual RStudio screenshots for submission.

## Dataset source
https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv

This is a public mirror of the Titanic passenger training dataset. The project is for educational data-cleaning practice, not for making historical or causal claims.
