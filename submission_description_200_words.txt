This report presents my Week 1 work for the Virtual R Data Analyst Internship. The project focuses on data cleaning, preprocessing and preliminary exploratory data analysis using the publicly available Titanic passenger training dataset. The dataset contains passenger-level information such as survival status, passenger class, sex, age, family counts, ticket details, fare, cabin and port of embarkation. It includes both numerical and categorical variables and contains missing values, making it suitable for practising data preparation in R.

The report explains the dataset source, its structure and the initial inspection performed with R functions such as dim(), str() and summary(). It documents the missing-value strategy: the median is used to fill missing age values, the most frequent category is used for missing embarkation values, and the cabin field is excluded from the analysis table because a large proportion of its entries are missing. The report also describes outlier detection for passenger fare using the interquartile range method. Outliers are flagged for review rather than automatically deleted, because unusual values may still be valid observations.

For preprocessing, age is standardized using a z-score, fare is scaled to a zero-to-one range, and categorical fields such as sex, embarkation port and passenger class are converted into factors and one-hot encoded for an example modelling-ready table. The exploratory analysis includes survival counts and proportions, grouped summaries, a numerical correlation matrix, and visualizations for age distribution, survival proportion by sex, fare by passenger class, and the relationship between age and fare.

The companion R script is included to make the workflow reproducible. It downloads the dataset from the stated public source, performs the cleaning steps, exports cleaned CSV files and saves charts and analysis outputs. The analysis is descriptive and educational; correlations and group differences are not treated as proof of causation.
